8.​ Create a pod named webserver.
Create an emptyDir volume name: shared-logs.
Create two containers from nginx and ubuntu images with latest tag only and remember
to mention tag i.e nginx:latest, nginx container name should be Nginx-container and
ubuntu container name should be sidecar-container on webserver pod.

Add command on sidecar-container "sh","-c","while true; do cat /var/log/nginx/access.log/var/log/nginx/error.log; sleep 30; done"
Mount volume /var/log/nginx on both containers, all containers should be up and Running.
